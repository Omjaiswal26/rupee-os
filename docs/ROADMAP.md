# Roadmap (post v0.1)

Track work as GitHub Issues. High-level themes:

1. **Payee & merchant coverage** — more Indian rails/narrations; fewer “DEP”/rail false merchants.
2. **Bank statement formats** — more column aliases; password-XLSX polish; sample packs per bank family.
3. **Month health** — MoM deltas; clearer drivers; stale regeneration after corrections.
4. **Year narratives** — richer overview; cross-month trends.
5. **DX** — one-command smoke test; classification preflight when the Ollama model is missing.
6. **Optional hosted demo** — read-only / synthetic-only public instance (no real user statements).

Non-goals for now: multi-user SaaS, cloud LLMs for statement text, mobile apps.
